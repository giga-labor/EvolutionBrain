# Security Policy

## Supported Versions
Questo repository e in fase attiva: si supporta il branch principale (`main`) e l'ultima release taggata.

## Reporting a Vulnerability
Non aprire issue pubbliche per vulnerabilita.

Invia una segnalazione privata con:
- descrizione del problema
- impatto atteso
- passi per riprodurre
- eventuale proof of concept

Se non hai un canale dedicato, apri una issue minimale senza dettagli sensibili chiedendo contatto privato.

## Response Goals
- presa in carico: entro 72 ore
- valutazione iniziale: entro 7 giorni
- patch/mitigazione: in base alla severita
