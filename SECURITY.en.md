# Security Policy

> Italian version: [SECURITY.it.md](./SECURITY.it.md)

## Supported Versions
Main branch (`main`) and latest tagged release are considered supported.

## Reporting a Vulnerability
Do not open public issues for vulnerabilities.

Use a private reporting channel including:
- problem description
- expected impact
- reproduction steps
- optional proof-of-concept

If no private channel exists, open a minimal issue without sensitive details and request a secure contact path.

## Response Goals
- acknowledgment: within 72 hours
- initial assessment: within 7 days
- mitigation timeline: severity-based
